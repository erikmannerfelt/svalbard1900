# Svalbard 1900

Camera stations of the Norwegian phototheodolite surveys of Svalbard (1906-1928), found by matching the
skylines of the plates to today's terrain: https://erikmannerfelt.github.io/svalbard1900/

This repository is generated; the code lives in a separate (private) project.

Credits: plates by the Norwegian Polar Institute, series NBR9201 (Fotoware previews). Terrain model (S0 DTM20),
orthophotos, maps and place names: Norwegian Polar Institute, CC BY 4.0. Station positions and viewer: Erik Schytt
Mannerfelt.
